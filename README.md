## Описание решений

### Средней сложности №8 — FastAPI принимает параметр и отвечает

Четыре эндпоинта, показывающие разные виды параметров:

- `/hello/{name}?lang=en` — параметр пути и необязательный параметр запроса
  с перечислением `Language` (в Swagger — выпадающий список);
- `/square/{number}` — автоматическое преобразование типа: строка из адреса
  становится `int`, на `/square/abc` FastAPI сам отвечает 422;
- `/calc?a=10&b=4&op=div` — обязательные и необязательные параметры запроса;
  деление на ноль — ответ 400 через `HTTPException`;
- `/age?birth_year=2006` — ограничения `Query(ge=1900, le=текущий год)`.

### Средней сложности №10 — простейший REST API списка задач

Полный набор операций над ресурсом `/tasks`:

| Метод | Адрес | Действие | Код ответа |
|---|---|---|---|
| GET | `/tasks` | список, фильтр `?done=true` | 200 |
| GET | `/tasks/{id}` | одна задача | 200 / 404 |
| POST | `/tasks` | создать | 201 |
| PUT | `/tasks/{id}` | заменить целиком | 200 / 404 |
| PATCH | `/tasks/{id}/done` | отметить выполненной | 200 / 404 |
| DELETE | `/tasks/{id}` | удалить | 204 / 404 |

Данные хранятся в памяти процесса. Схемы разделены: `TaskIn` — то, что
присылает клиент (без id), `Task` — то, что возвращает сервер.

### Средней сложности №4 — страница с таблицей данных

Flask-страница с успеваемостью студентов, шаблон Jinja2:

- сортировка по любой колонке щелчком по заголовку (повторный щелчок
  меняет направление, активная колонка отмечена стрелкой);
- фильтр по группе через форму с методом GET;
- строка итогов со средними по предметам, пересчитывается при фильтрации;
- подсветка пятёрок и неудовлетворительных оценок CSS-классами.

Параметры из адресной строки проверяются: неизвестное значение сортировки
заменяется значением по умолчанию, а не вызывает ошибку.

Использованы возможности Jinja2: наследование шаблонов (`{% extends %}`),
макрос для заголовка колонки (`{% macro %}`), циклы с `{% else %}`
для пустой таблицы, фильтры `format` и `length`, переменная `loop.index`.

### Повышенной сложности №8 — Pydantic-схемы

Две связанные сущности — пользователи и заказы:

- **ограничения полей** через `Field`: длина, диапазон, регулярное выражение
  (имя пользователя, email, почтовый индекс);
- **проверка поля** `@field_validator`: пароль должен содержать буквы и цифры,
  ФИО приводится к виду «Иванов Иван», промокод — к верхнему регистру;
- **проверка модели целиком** `@model_validator`: пароль и подтверждение
  совпадают;
- **вложенные модели**: адрес внутри пользователя, список позиций внутри заказа;
- **вычисляемые поля** `@computed_field`: сумма по позиции, итог заказа,
  скидка по промокоду;
- **три схемы для одной сущности**: `UserCreate` (вход, есть пароль),
  `UserInDB` (хранение, есть хеш), `UserOut` (ответ, нет ни того, ни другого).
  `response_model=UserOut` гарантирует, что пароль не уйдёт клиенту;
- **частичное обновление** `PATCH` через `model_dump(exclude_unset=True)`.

### Повышенной сложности №1 — Flask с базой SQLite (CRUD)

Домашняя библиотека: список книг с поиском, добавление, редактирование,
удаление и быстрая отметка «прочитано».

- Соединение с базой — одно на запрос, хранится в `flask.g`,
  закрывается в `@app.teardown_appcontext`.
- Все запросы параметризованы (`?` и `:имя`), подстановки через f-строки
  нет — SQL-инъекция невозможна. Проверено запросом `' OR 1=1 --`.
- Проверка формы на сервере; при ошибке форма возвращается
  с уже введёнными значениями и списком ошибок (код ответа 400).
- После успешного POST — перенаправление (Post/Redirect/Get),
  чтобы обновление страницы не отправило форму повторно.
- Удаление — только методом POST; на GET сервер отвечает 405.
- Поиск не зависит от регистра и для кириллицы: встроенные `LIKE`
  и `lower()` SQLite работают с регистром только латиницы, поэтому
  в базу подключена питоновская функция `py_lower`.
- База `library.db` создаётся сама при первом запуске
  и заполняется четырьмя книгами.

## Связь заданий

- `main.py` объединяет все пять приложений на одном сервере:
  FastAPI-приложения подключены через `mount()`, Flask-приложения —
  через переходник `a2wsgi` (Flask работает по стандарту WSGI, FastAPI — по ASGI).
- Оба Flask-приложения используют общий базовый шаблон `templates/base.html`
  и общие стили `static/style.css`.
